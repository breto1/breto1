---

## 🚀 Pilar Layanan & Keahlian Utama (PandaKode Ecosystem)

* 📱 **Mobile App Development:** Membangun aplikasi Android modern, cepat, dan aman menggunakan **Kotlin (Jetpack Compose)** dan **Flutter** yang siap dipublikasikan ke Google Play Store.
* 🌐 **Full-Stack Web Systems:** Pengembangan sistem informasi korporasi/akademik, *micro-sites*, e-learning (Moodle & H5P), serta integrasi REST API menggunakan **PHP, Python (Flask), JavaScript, Bootstrap, dan MySQL**.
* 📡 **Internet of Things (IoT) & Smart Systems:** Perancangan perangkat keras dan *dashboard monitoring real-time* berbasis **ESP32, Raspberry Pi, Mosquitto MQTT Broker**, serta berbagai sensor industri (PZEM, DHT, GPS, RSSI Wi-Fi Indoor Positioning).
* 🧠 **Data Science, Machine Learning & Local AI:** Analisis data dan pemodelan cerdas menggunakan **Python (Scikit-Learn, TensorFlow, Pandas, NumPy)** serta implementasi infrastruktur LLM lokal (**Ollama, Open WebUI, Docker**).
* 🎮 **Game Development & Interactive EdTech:** Perancangan mekanik permainan (*Trading Card Game / 2D Strategy*) menggunakan **Godot Engine** dan modul edukasi interaktif untuk anak-anak.
* 🖨️ **3D Printing & Rapid Prototyping:** Desain 3D CAD, operasional manufaktur aditif, dan pelatihan teknis pencetakan 3D.
